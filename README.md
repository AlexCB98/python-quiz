# Python Quiz Game

A command-line quiz game built with Python.

--- 

## How to play
- Answer each question by typing "a" or "b"
- You have 5 lives
- Wrong answer = lose a life
- Game ends when you run out of lives or finish all questions

---

## Features
- 25 Python questions
- Random question order each game
- Live score and lives tracking

---

## How to run
```bash
python main.py
```

---

## Built with
- Python 3
- random module
